# 📦 Marketing Campaign Analysis for Food Delivery Service (karpov.course)

## 📌 Project Overview

This project presents a comparative analysis of two marketing campaigns for a food delivery service.

**Objective:**  
To determine which acquisition channel delivers more sustainable and profitable users based on unit economics and retention metrics.

We compared:

- 📢 Campaign #1 — YouTube food blogger integration  
- 🎯 Campaign #2 — Targeted social media advertising  

Each campaign had a total budget of **250,000 RUB**.

---

## 🎯 Business Questions

1. Which channel acquires users at a lower cost? (CAC)
2. Which campaign is more profitable? (ROI)
3. Are there differences in user purchasing behavior? (Average Order Value)
4. Which audience demonstrates better retention?
5. Which channel should be scaled?

# 📈 Key Results

| Metric | Campaign #1 (Blogger) | Campaign #2 (Targeted Ads) |
|--------|-----------------------|----------------------------|
| CAC | 1,461 RUB | **1,068 RUB** |
| ROI | **+14.5%** | -1.61% |
| Average Order Value | 371 RUB | **380 RUB** |
| D1 Retention | **42%** | 17% |
| D7 Retention | **22%** | 9% |

---

# 🔍 Core Insight

Although Campaign #2 demonstrated a lower CAC and slightly higher average order value, its retention metrics were significantly weaker.

As a result:

- Campaign #2 generated negative ROI
- Campaign #1 achieved positive return due to stronger user retention

The key differentiator was not acquisition cost, but repeat purchase behavior.

---

# 🧠 Product Thinking

For a food delivery service, sustainable growth is driven by:

Retention → Order Frequency → LTV → ROI

A low CAC does not guarantee profitability if users do not return.

When evaluating marketing channels, it is critical to analyze:

- CAC
- Retention
- LTV
- ROI
- Payback period

---

# 🚀 Business Recommendations

- Scale influencer-based acquisition strategy
- Reassess targeting strategy in paid ads
- Improve onboarding and retention mechanics for cold traffic
- Continuously monitor cohort performance before budget scaling
